# Assignment
## Task 1: Python + API
Run the script to get weather information for a given city.
```
python weather.py
```
Replace `"your_api_key_here"` with a valid OpenWeatherMap API key.

## Task 2: SQL Queries
The `queries.sql` file contains:
- Total amount by each customer
- Orders after a certain date
- Customers with multiple orders

## Task 3: Flask App (Bonus)
Run the Flask server:
```
python app.py
```
Then visit:
```
http://127.0.0.1:5000/weather?city=London
```
